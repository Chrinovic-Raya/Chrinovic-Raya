## Featured Projects

### Batch ETL Pipeline (in progress)

My first data engineering project. A pipeline that pulls daily weather data for four South African cities from the Open-Meteo API, cleans and validates it, and loads it into a database.

| Stage | What it does | Tools |
|---|---|---|
| Extract | Calls the Open-Meteo API for each city and handles request errors | Python, Requests |
| Transform | Cleans, types and validates the data, and flags missing or out-of-range values | Pandas |
| Load | Writes to the database and skips duplicate loads for the same day | SQLAlchemy, SQLite |
| Configuration | Keeps settings and credentials out of the code | python-dotenv |
| Engineering practice | Logging, docstrings, type hints and version control | Python logging, Git, GitHub |
| Next stages | Daily scheduling, data quality checks, unit tests, PostgreSQL | Apache Airflow, Pytest, PostgreSQL |

[View the repository](https://github.com/Chrinovic-Raya/batch-etl-pipeline)
